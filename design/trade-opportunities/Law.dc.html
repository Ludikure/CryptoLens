THE DESIGN, IN ONE PAGE
Colour means one thing each.
This is the rule that removes the need for a legend inside the app. If a colour ever has to be explained on the screen it is being used wrongly.
Blue — something you could start
The leading stripe on a card, and the edge number. Nothing prospective is ever green: a proposal is not money.
Green — money that already exists
Only on an open position, only on realised R. It appears nowhere else on the screen, which is what keeps it meaning something.
Orange — a hazard that changes what you would do
A size cut, a drawdown reading. It gets a full-width hairline rather than a leading stripe, so it can never be mistaken for something to act on.
Grey — unranked, or unmodelled
Longs, no-view assets, everything the envelope stopped. No card, no columns — the shape says "not a candidate" before you read a word.
